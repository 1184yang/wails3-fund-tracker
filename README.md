# wails3-fund-tracker
## 定期定額基金損益追蹤系統
1. 在你的電腦建立一個資料夾（例如 D:\MyFundTracker\），把 .exe 複製進去即可直接雙擊啟動。

2. 執行時如果出現此警告,按 <ins>其他資訊</ins> 就會出現 <ins>仍要執行</ins> 按鍵

   Microsoft Defender SmartScreen 已防止某個無法辨識的應用程式啟動。執行此應用程式可能會讓您的電腦暴露在風險中。

3. 資料庫使用的是 Sqlite3，會自動產生在 ./data 目錄下。

4. 日常備份只需定期將 D:\MyFundTracker\data\db01.sqlite 複製一份，或使用系統內建的「匯出 CSV 備份」功能即可。


## 系統說明

基於 **Go + Wails v3 + SQLite3 + Bootstrap 5 + Chart.js** 開發的本機個人基金記帳與損益分析桌面軟體。所有前端資源皆內嵌於單一執行檔中，支援 100% 離線使用。

---

### 一、 核心功能總覽

1. **投資組合儀表板**：即時計算當前未贖回部位的持有成本、最新市值、帳面未實現損益、報酬率與牛頓法 **XIRR（年化內部報酬率）**。
2. **雙圖表視覺分析**：
   - 累積投入成本 vs. 資產總值折線走勢圖（支援一鍵收合與狀態記憶）。
   - 各基金市值配置佔比圓餅圖。
3. **五大管理分頁**：
   - **目前持有基金明細**：檢視各標的庫存單位數、平均成本與最新報價損益。
   - **歷史交易與配息紀錄**：完整支援申購（`BUY`）、贖回（`SELL`）、現金配息（`DIV_CASH`）、配息再投資（`DIV_REINVEST`）之新增、編輯與刪除。
   - **已實現贖回損益**：採用移動平均成本法，獨立統計每次贖回的賣出成本、入帳金額與已實現獲利。
   - **歷史淨值與匯率**：批次或單筆更新最新淨值，選擇單一基金時右側自動繪製**近一年淨值走勢與平均成本基準線**。
   - **基金標的清單**：管理投資與觀察名單標的（ISIN 代碼、計價幣別、配息類型）。

---

### 二、 資料庫位置與自動備份還原

- **資料庫路徑**：程式啟動時會自動在執行檔同級目錄建立 `data/db01.sqlite`。
- **每日自動備份**：每次開啟程式時，系統會自動將資料庫備份至 `data/backups/db01_YYYYMMDD.sqlite.bak`（自動保留最近 7 份快照）。
- **手動還原步驟**：
  1. 完全關閉基金追蹤系統視窗。
  2. 進入 `data/backups/` 資料夾，找到欲還原日期的 `.bak` 檔案。
  3. 將該檔案複製回上一層 `data/` 資料夾，並重新命名為 `db01.sqlite`（覆蓋原檔）後重新啟動程式即可。

---

### 三、 CSV 匯出與批次匯入格式

在「歷史交易與配息紀錄」分頁右上角可使用原生系統對話框進行 CSV 匯出（UTF-8 BOM 編碼，Excel 開啟不亂碼）與批次匯入。

匯入時系統會依據 **ISIN代碼** 自動對應基金（若標的尚未建立會自動新增），標準 10 個欄位順序如下：

| 欄位順序 | 欄位名稱   | 說明與填寫範例                                 |
| :------- | :--------- | :--------------------------------------------- |
| 1        | `ISIN代碼` | 基金唯一識別碼，例如 `TW000T0114B7`            |
| 2        | `基金名稱` | 例如 `安聯台灣科技基金`                        |
| 3        | `幣別`     | 計價幣別，如 `TWD`、`USD`、`EUR`、`JPY`        |
| 4        | `配息類型` | `ACC`（累積型）或 `DIST`（配息型）             |
| 5        | `交易日期` | 格式固定為 `YYYY-MM-DD`，例如 `2026-11-18`     |
| 6        | `交易類型` | 僅限 `BUY`、`SELL`、`DIV_CASH`、`DIV_REINVEST` |
| 7        | `交易金額` | 原幣交易或配息金額（純數字）                   |
| 8        | `成交淨值` | 成交當日原幣淨值（現金配息填 `0`）             |
| 9        | `單位數`   | 成交單位數（現金配息填 `0`）                   |
| 10       | `成交匯率` | 該筆交易原幣對台幣匯率（台幣基金固定填 `1`）   |
